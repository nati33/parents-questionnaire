# שאלון הורים 5–10

אפליקציית שאלון להורים לילדים בגילאי 5–10, שמובילה לבניית תכנית התערבות מותאמת אישית.
זהו הבסיס לפלטפורמת **תכניות התערבות** עתידית שתעמוד מעל השאלון.

## מצב נוכחי (Phase 1 — Static MVP)

- ✅ **v6** של השאלון: 124 שאלות סולם + 6 פתוחות/צ׳קבוקס, מפוצלות ל-14 חלקים
- ✅ **3 הפוגות אינטראקטיביות** במהלך השאלון:
  - 🌳 דיוקן עץ שגדל (אחרי חלק ג׳)
  - 📊 גרף אנרגיה רדאר + רגע נשימה (אחרי חלק ה׳)
  - 🎯 חזון תכנית — 3 כיווני התערבות (אחרי חלק ח׳)
- ✅ **אימות מקומי**: הרשמה / כניסה / שחזור סיסמה במייל
- ✅ **לוח אדמין מקומי**: ניהול הגשות, ייבוא JSON, ייצוא Word
- ✅ **שמירה אוטומטית** של ההתקדמות (localStorage)
- ✅ **עיצוב מודרני** מותאם מובייל ו-RTL מלא

## הרצה מקומית

### מצב 1 — לחיצה כפולה (סטטי, ללא תלויות)
פתחו ישירות `public/index.html` בדפדפן. הכול עובד מקומית — אין צורך בשרת.

### מצב 2 — Vite dev server (לפיתוח עתידי)
```bash
npm install
npm run dev
```
Vite ירים שרת מקומי ויאפשר hot-reload.

### בנייה לפרודקשן
```bash
npm run build
```
התוצר ב-`dist/` — מוכן להעלאה ל-Netlify / Vercel / Cloudflare Pages.

## פרסום מהיר (ללא Vite)

תיקיית `public/` היא סטטית לחלוטין. לפרסום מהיר ללא בנייה:

1. **Netlify Drop**: https://app.netlify.com/drop — גרור את `public/` ותקבל URL ציבורי
2. **Cloudflare Pages**: חבר את הריפו, build command ריק, output `public`
3. **GitHub Pages**: push לענף `gh-pages` עם תוכן `public/`

ראה [ROADMAP.md](ROADMAP.md) לתכנון השלבים — backend אמיתי, סנכרון בין מכשירים, פלטפורמת תכניות התערבות.
